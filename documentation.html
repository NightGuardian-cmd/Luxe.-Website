Section 01

Project Overview

LUXE is a fully responsive, multi-page premium e-commerce website built with native HTML, CSS, and JavaScript — no frameworks, no libraries, no shortcuts. It simulates a real-world luxury fashion store with a complete shopping journey from browsing to checkout.

Section 02

File Structure

The project is cleanly separated into three core files following the requirement to split HTML, CSS, and JavaScript:

LUXE-Project/
  ├── index.html   ← All 10+ page sections (SPA structure)
  ├── style.css    ← All styling, animations, responsive breakpoints
  ├── script.js    ← All JS logic: DOM, Events, Cart, Auth, Clock
  └── documentation.html  ← This file — project documentation

The website uses a Single Page Application (SPA) pattern — all pages live inside one HTML file and are shown/hidden dynamically using JavaScript and CSS classes. This avoids the need for a backend or server while still feeling like a multi-page site.

Section 05

Responsive Design

The website is fully responsive across all device sizes using CSS Grid, Flexbox, and media queries:

📱

Mobile

≤ 768px — Hamburger menu, stacked layouts, single-column grids

📟

Tablet

769px – 1100px — 2-column grids, auth visual hidden, footer 2-col

💻

Desktop

≥ 1101px — Full layout with sidebar, 3-4 col grids, hero split view

  • Hamburger Menu: Navigation collapses into a toggle button on mobile, expanding as an overlay menu
  • CSS Grid auto-fill: Product grids use minmax(280px, 1fr) to adapt to any screen width
  • Sticky header: Stays at top with blur backdrop on all screen sizes
  • Scroll behavior: scroll-behavior: smooth for native smooth scrolling
Section 06

Login & Registration Validation

The login page uses full client-side validation before allowing access to the home page. No blank fields are allowed and email format is checked with regex.

Login Validation Rules

  • Email field must not be empty
  • Email must match valid format (regex: /^[^\s@]+@[^\s@]+\.[^\s@]+$/)
  • Password must not be empty and must be at least 6 characters
  • Error messages displayed inline using flash component

Register Validation Rules

  • First name, last name, email, password, confirm — all required
  • Email must match valid format
  • Password must be at least 8 characters
  • Password must contain at least one uppercase letter (A–Z)
  • Password must contain at least one number (0–9)
  • Confirm password must match password exactly
  • All validation errors shown with a red flash message above the form

Upon successful login/register, the user is stored in localStorage and their name is displayed in the Account page greeting.

Section 08

Deployment on GitHub Pages

To deploy this project on GitHub Pages, follow these steps:

  1. Create a new public repository on github.com (e.g. luxe-ecommerce)
  2. Upload the three project files: index.html, style.css, script.js
  3. Go to repository Settings → Pages
  4. Under "Branch", select main and folder / (root)
  5. Click Save — GitHub will generate a live URL within a few seconds
  6. Share the URL: https://yourusername.github.io/luxe-ecommerce/

Why GitHub Pages works perfectly

Because LUXE uses only static files (HTML, CSS, JS) with no server-side code, GitHub Pages hosts it for free with zero configuration. All data (cart, wishlist, user session) is stored in the browser's localStorage.
